# श्री कृष्ण जन्माष्टमी • Janmashtami Festival Celebration Website

A premium, responsive, and traditionally rich **Janmashtami Festival Website** built with **React + Vite**, **React Router**, and **Tailwind CSS**.

---

## ✨ Features & Pages

1. **Home (`/`)**:
   - Cinematic hero section with golden glowing aura, Sanskrit heading *"श्री कृष्ण जन्माष्टमी"*, subheading *"Celebrate the Divine Birth of Lord Krishna"*.
   - Krishna silhouette, peacock feather, flute, floating golden particles, and traditional motifs.
   - Primary CTA *"Explore Janmashtami"*.
   - Festival essence, Why Janmashtami is celebrated, sacred Bhagavad Gita quote card, and celebration highlights.

2. **About Janmashtami (`/about`)**:
   - Spiritual significance, divine advent of Lord Krishna in Mathura's prison, crossing of Yamuna to Gokul.
   - Sacred traditional practices (fasting, abhishek, bhog, cradle ceremony).
   - **"Our Little Krishna" Photo Carousel**: Dedicated section featuring large rounded images, golden glowing borders, auto-slide with play/pause, navigation arrows, indicator dots, and touch swipe.

3. **Celebration (`/celebration`)**:
   - **Dahi Handi**: Human pyramids, Govinda chants, butter pot traditions.
   - **Tamil Uriyadi**: The swaying pot challenge, turmeric water showers, community festivities.
   - **Krishna Jayanthi Pooja**: Midnight pooja rituals, Vennai (butter), Seedai, Murukku, Aval offerings.
   - **Decorations**: Peacock feathers, flute, baby footprints (*Kannan Paadam*), brass diyas, fresh flowers, and rangoli/kolam.
   - **Interactive Celebration Timeline**: From dawn Brahma Muhurta to midnight Janmotsav and next-day festivities.

4. **Festive Photo Gallery (`/gallery`)**:
   - Filterable categories: *All*, *Krishna*, *Janmashtami*, *Decorations*, *Dahi Handi*, *Pooja*.
   - High-resolution royalty-free imagery with graceful fallbacks.
   - Hover zoom effects, category badges, overlay titles.
   - Full-screen interactive **Lightbox** with previous/next controls, keyboard escape support, and captions.

5. **Navigation & Footer**:
   - Glassmorphic sticky Navbar (*JP • Janmashtami*) with active indicators and mobile drawer menu.
   - Traditional golden accent Footer with Hare Krishna Maha Mantra tribute, social sharing, and quick navigation.
   - Floating particle canvas background.

---

## 🖼️ How to Replace "Our Little Krishna" Photos

To use your own children's photos in the carousel, simply drop your pictures with the following file names into the `public/assets/` folder:

```
public/assets/
├── kutty1.jpg
├── kutty2.jpg
├── kutty3.jpg
└── kutty4.jpg
```

No code changes are required! The carousel will automatically display your photos.

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```

### 4. Preview Production Build
```bash
npm run preview
```
